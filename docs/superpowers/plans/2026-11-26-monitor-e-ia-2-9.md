# Monitor do PC e consumo das IAs (2.9) — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mostrar no celular/tablet o uso do PC (CPU, memória, disco, rede, GPU, temperaturas, processos) e o limite de uso do Claude/Codex (5 h e semanal: % usado, quanto falta, reinício).

**Architecture:** Dois módulos novos no servidor (`streamdeck/monitor.py`, `streamdeck/ia.py`) que coletam em segundo plano só quando algum aparelho pede; dados expostos em `GET /api/state` (resumo) e `GET /api/monitor` (detalhe). Celular ganha textos ao vivo novos e uma página "Monitor" (lista de processos). Editor ganha as opções e um cartão "Consumo das IAs" com o botão para instalar a ponte da status line do Claude Code.

**Tech Stack:** Python 3.8+ stdlib (ctypes: `GetSystemTimes`, `GlobalMemoryStatusEx`, `GetDiskFreeSpaceExW`, `GetIfTable2`/`GetIfEntry2`, PDH para GPU `\GPU Engine(*)\Utilization Percentage`, `CreateToolhelp32Snapshot`+`GetProcessTimes`+`GetProcessMemoryInfo`, `OpenProcess`+`TerminateProcess`), ES5 no front-end.

**Spec:** `docs/superpowers/specs/2026-11-26-melhorias-2-9-design.md`

## Global Constraints
- Sem dependências novas; sem PowerShell/WMI/subprocess para coletar métricas.
- Fora do Windows: valores simulados determinísticos (testes rodam no Linux).
- Não ler credenciais de IA; Claude só via status line documentada (`rate_limits.five_hour|seven_day.used_percentage|resets_at`).
- Encerrar processo: só do próprio PC ou de aparelho com permissão (2.10); na 2.9 = só do próprio PC ou com confirmação no aparelho **e** opção "Permitir encerrar programas pelo celular" ligada em Conectar (padrão desligada). Nunca encerrar PID 0/4, o próprio Stream Deck, `csrss.exe`, `wininit.exe`, `winlogon.exe`, `lsass.exe`, `services.exe`, `smss.exe`, `explorer.exe`.
- Coleta só roda se `/api/state` ou `/api/monitor` foi chamado nos últimos 60 s (como `tocando`).
- Textos em pt-BR; comentários sem acento; ES5.

## Review Focus
- Ponte da status line quando o usuário já tem uma status line própria: a dele continua funcionando (saída repassada).
- Arquivo `claude.json` antigo (Claude Code fechado há dias): mostrar "atualizado há X" e não números como se fossem atuais; janela cujo `resets_at` já passou = 0% usado.
- Codex sem registros ou com formato desconhecido: "indisponível", nunca erro na página.
- LibreHardwareMonitor fechado/porta errada: temperatura some sem atrasar `/api/state` (timeout curto, cache).
- Encerrar processo protegido ou já encerrado: mensagem clara, nada quebra.
